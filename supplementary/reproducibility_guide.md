**Reproducibility Guide**

**Purpose**

This guide provides step-by-step instructions to reproduce all results, figures, and outputs generated by the dissertation implementation.

**Environment**
  
  - Python 3.10
  - Google Colab (recommended) or local Jupyter environment
  - Libraries listed in requirements.txt

**Steps to Reproduce**

  1. Clone the repository or download the ZIP archive.
  2. Open notebook/CostOverrunPrediction.ipynb in Google Colab.
  3. If running locally, install dependencies: pip install -r requirements.txt
  4. Ensure the dataset folder contains:
      - bim_ai_dataset.csv
      - fred_indicators.csv
  5. Run all cells in the notebook from top to bottom.
  6. Outputs are automatically saved to:
      - outputs/figures
      - outputs/tables
      - outputs/logs
  7. Trained models will be saved in the models/ folder.

**Random Seeds**

Reproducibility is preserved through fixed random seeds throughout the notebook.

**Expected Runtime**

Approximately 10 to 20 minutes depending on Colab environment.

**Notes**

The workflow reproduces:

  - All preprocessing and feature engineering outputs
  - Model training and hyperparameter tuning results
  - Validation and test evaluation metrics
  - ROC curves, confusion matrices, precision-recall curves, and calibration curves
  - Risk category validation outputs
  - SHAP global summary, dependence, and local explanation plots

Refer to docs/methodology_notes.md for a summary of the workflow and to Chapters 3, 4, and 5 of the dissertation for full methodological detail.
