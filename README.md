Early-Stage Construction Cost Overrun Prediction Using Machine Learning and Macroeconomic Indicators
Overview
This repository contains the code, datasets, trained models, outputs, and supporting documentation for the master's dissertation on early-stage prediction of construction cost overruns. The framework integrates pre-construction project characteristics with macroeconomic indicators and applies SHAP-based interpretability to enhance transparency.

Repository Structure:
  notebook/ – Colab notebook and rendered PDF
  proposal/ – Approved research proposal (historical planning document)
  dataset/ – BIM-AI dataset and FRED macroeconomic indicators
  models/ – Trained models for Model A and Model B
  outputs/ – Figures, tables, and logs generated during execution
  docs/ – Methodology and interpretation notes
  supplementary/ – Data dictionary and reproducibility guide

Environment:
  Google Colab (primary implementation environment)
  Python 3.10
  Libraries listed in requirements.txt

Getting Started:
  1.Clone the repository or open the notebook in Google Colab.
  2.Install dependencies: pip install -r requirements.txt
  3.Open notebook/CostOverrunPrediction.ipynb.
  4.Follow the reproducibility guide in supplementary/reproducibility_guide.md.

Notes:
The research proposal is included as a historical planning document. Methodological refinements introduced during the dissertation are documented in the dissertation appendix and referenced in proposal/PROPOSAL_NOTES.md.
